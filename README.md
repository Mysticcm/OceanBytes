# Ocean Bytes

## What is Ocean Bytes?

Landingpage for a saas service, where customers can add orders or send requests, and admin can manage them. 

Goal is to deliver saas, and utilize the webpage for orders and management of orders. 

## Quick start: 

    - Download project
    - Open in chosen ide
    - create a .env file in root directory, and add variable (example): 
        mongodb = "mongodb://###.#.#.#:#####/oceanbytes"
    - commandline: 
        - to install dependencies: npm i
        - start program: npm start

    App runs on localhost:3333, hardcoded value in app.js line 59
